# 🚀 CareerLaunch

### Launch Your Career With Confidence.

CareerLaunch is a modern, AI-generated **student career platform concept** designed to help students discover career opportunities, build resumes, develop skills, explore career paths, and prepare for interviews — all through a single platform.

> **⚠️ Disclaimer:** CareerLaunch is a **demo and educational project** created as part of an AI Website Generation task. It is not currently a production or commercial platform. Some features are UI demonstrations only.

---

## 🌐 Live Demo

🔗 **[Visit CareerLaunch](https://careerlaunchtest.netlify.app/)**

---

## ✨ Features

### 📄 AI Resume Builder

Create and improve professional, ATS-friendly resumes with AI-inspired suggestions.

### 💼 Internship Finder

Explore internship opportunities based on skills and interests.

### 🗺️ Skill Roadmaps

Follow structured learning paths to develop skills for different career fields.

### 🎤 Interview Preparation

Practice interview questions and improve your interview confidence.

### 🧭 Career Guidance

Explore different career paths and understand the skills required for them.

### 📊 Progress Dashboard

Track learning progress, career goals, skills, and opportunities.

### 📚 Career Resources

Access demo resources covering resumes, internships, interviews, and career development.

## 🔐 Demo Functionality

Some features are intentionally **UI-only** because this project was created as a website-generation demonstration.

### Login

The **Login** option is included in the interface for demonstration purposes.

> Authentication, user accounts, and backend login functionality are **not implemented**.

### Contact Form

The contact form demonstrates the frontend interaction and success state.

> No real messages are sent to a backend.

### Career Data

Career paths, statistics, testimonials, and other platform content are **sample/demo content** and should not be interpreted as real platform data.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/careerlaunch.git
```

### 2. Navigate to the project

```bash
cd careerlaunch
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open in browser

```text
http://localhost:5173
```

---

## 📦 Build for Production

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```
